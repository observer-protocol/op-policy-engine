# SRF SCALE: a synthetic claim corpus over the Shared Responsibility Framework register

**SYNTHETIC. DEMONSTRATION-KEY.** Nothing here measures any bank, Telco, account holder, claimant
or incident. Session CORPUS-SRF-SCALE, 2026-08-25, over `policy-library/mas-srf-2024` at tag
`srf-register-accepted-v1`.

| file | what |
|---|---|
| `ANNEX.md` | the measurement annex: N, construction, coverage, outcome distribution, the headline with its denominators, verification, tamper test, key custody. Generated by `annex.mjs`; no figure is typed by hand |
| `FINDINGS.md` | numbered findings S-01 onward: register findings (logged, not tuned) and this corpus's own |
| `build.mjs` | constructs the corpus, runs the engine (interpreter + router) with the hand evaluator beside it as a parity control, signs every record with an ephemeral key, writes `out/` |
| `project.mjs` | the claim-level projection of a v7 record set (outcome, tier, open clauses, duty statuses); shared by build and verify, stated as such |
| `verify.mjs` | external verification: signatures via the published `@observer-protocol/policy-engine`, and a rebuild of every record from corpus + engine |
| `tamper.mjs` | post-signing modification of one field per case; the verifier must pass the original and fail the copy |
| `annex.mjs` | generates `ANNEX.md` from `out/*.json` and the records |
| `lib.mjs` | JCS, base58, did:key, delta helpers used by the builder |
| `out/corpus.jsonl.gz` | one claim per line: population, the clause varied, facts as a delta over `cases.mjs` base (or in full), resolutions |
| `out/records.jsonl.gz` | one signed claim record per line (eddsa-jcs-2022 DataIntegrityProof) |
| `out/exhibits/` | one full v7 record set per outcome-and-tier reached, signed; and the tampered copies, which must not verify |
| `out/manifest.json`, `measurement.json`, `verification.json`, `tamper-test.json` | the run's key and digests, the measurements, the verifier's outputs |

Rerun (a new key each time; the corpus is seeded and byte-stable apart from the proofs):

```
node build.mjs --created <ISO instant>
node verify.mjs --engine <dir of an installed @observer-protocol/policy-engine>
node tamper.mjs --engine <same dir>
node annex.mjs
```
